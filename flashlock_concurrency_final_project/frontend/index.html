Why is this strategy faster or slower? — Atomic Update

The database performs the stock check and stock decrement as one atomic SQL statement. This minimizes application-level coordination and avoids holding a row lock across a multi-step transaction, providing high throughput for single-row flash-sale updates. 

UPDATE products SET stock = stock - ?, version = version + 1 WHERE id = ? AND stock >= ?;
